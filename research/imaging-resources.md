Select resources for neuroimaging clinician researchers.

### Software

- [FSL](https://fsl.fmrib.ox.ac.uk/) — FMRIB Software Library (Oxford)
- [SPM](https://www.fil.ion.ucl.ac.uk/spm/) — Statistical Parametric Mapping (UCL)
- [FreeSurfer](https://surfer.nmr.mgh.harvard.edu/) — Cortical surface reconstruction
- [AFNI](https://afni.nimh.nih.gov/) — Analysis of Functional NeuroImages (NIH)

### Data repositories

- [OpenNeuro](https://openneuro.org/) — Open neuroimaging dataset repository
- [NeuroVault](https://neurovault.org/) — Statistical maps repository

### Useful links

- [The Clinical Neurosciences Imaging Center (Yale)](http://cnic.yale.edu/)
- [NITRC — Neuroimaging Tools & Resources](https://www.nitrc.org/)
